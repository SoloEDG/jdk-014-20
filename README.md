# PANEL

安装：`npm install`

本地启动：`npm run dev`

生产构建：`npm run typecheck && npm run build`

逻辑测试：`./node_modules/.bin/esbuild scripts/logic-test.mts --bundle --platform=node --format=esm --outfile=/tmp/logic-test.mjs && node /tmp/logic-test.mjs`

Docker 启动：`docker compose up --build`，访问 http://localhost:3014。

## 区域级收藏集（v2）

- 阅读时点「框选收藏」或按 `S`，在当前分镜内拖出选区，命名并归入收藏集；
  选区以**格内归一化坐标**（0–1）保存，点击收藏直接放大到该区域。
- 收藏预览的声景与对白取自**目标分镜**；预览不污染阅读进度，
  点「返回续读」或按 `Esc` 回到收藏前的正式续读点。
- 跨页复制分镜、分镜裁切、替换页面图片后，系统依据**分镜结构指纹**与
  **页面图像感知哈希（dHash）**核对每条收藏：仍准确的保持可用，
  失效的明确标记原因（分镜缺失 / 几何裁切 / 内容修改 / 图像替换），
  **旧坐标绝不静默套用到新画面**，需用户显式「重新定位」。
- 重新定位只修改当前这一条收藏，同一收藏集内其他位置不受影响。
- 证据缩略图为可选功能：仅保存选区的 160px JPEG 小图而非整张旧图，
  可设置容量上限（MB）；超额时先弹出**清理影响预览**，确认后才按
  最久未更新优先清理，坐标与收藏记录始终保留。
- 删除收藏集前可导出其中全部记录（含坐标、状态与可选证据）为 JSON。
- v1 整格书签在首次打开时自动迁移为格内全区域收藏。
